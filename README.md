## 📌 Overview

**LegalMarketing** is a performance-driven landing page ecosystem and conversion funnel crafted specifically for law firms, independent attorneys, and specialized legal practices (Real Estate Law, Civil Litigation, and Commercial Advisory).

Designed in strict compliance with bar association ethics guidelines (OAB compliance), it features telemetry-enabled WhatsApp click tracking, Google Ads conversion beacons, fast serverless API endpoints, and real-time visitor deduplication via Upstash Redis.

---

## ✨ Key Features

- 🎯 **OAB-Compliant Lead Architecture:** Ethical, informative copywriting structured around real legal pain points.
- 📊 **Google Ads GA4 Conversion Radar:** Custom script integrations firing precise conversion events upon contact intent.
- ⚡ **Upstash Redis Caching:** Serverless rate limiting, lead capture queuing, and deduplication.
- 📱 **Mobile-First UX:** Tailored for paid traffic campaigns with sticky call-to-actions and sub-second load times.
